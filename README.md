Nome do Sistema: Bah Games 

Objetivo:
O objetivo do programa é desenvolver um sistema de distribuição de jogos virtuais para a plataforma de
computadores pessoais(PC), semelhante a Steam.

Problema:  
A Steam monopoliza o mercado de jogos, diante disso, pretende-se criar uma concorrente visando atacar
problemas estruturais, tais como uma interface otimizada, preços acessíveis e lançamentos em tempo inédito
a comparar com a concorrência.

Público-Alvo: 
Devido a variedade de jogos, o sistema busca atender toda as faixas etárias. 

Principais Funcionalidades:
Permitir Cadastro de Usuários;
Catalogar Jogos;  
filtros otimizados;
Lista de Desejos do Usuário,
Biblioteca;

O que não fará parte:
Sistema Compras;
Controle de Pais;
Personalização do Sistema;
